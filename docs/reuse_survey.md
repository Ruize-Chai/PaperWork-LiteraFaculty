# Reuse survey

Survey date: 2026-10-06. Sources are primary project or service documentation. The checkout was empty apart from `.gitignore`; network access to GitHub from the execution runtime was unavailable, so repository-specific installed-component discovery could not be done. No external source code was copied. License and release details below are starting points for integration review and must be pinned/rechecked before adding dependencies.

## Evaluation criteria and outcome

Candidates were compared for licensing, current maintenance/documentation, scientific adoption, portability, dependency weight, extensibility, offline use, deterministic behavior, API stability, and output quality. v0.1 prioritizes portability and deterministic offline operation. The selected external-component list is empty; Python itself is the runtime. The future likely composition is Pydantic or a full JSON Schema validator at the boundary, Pandoc plus CSL for formatting, and separate Crossref/OpenAlex adapters for metadata. Those systems have different licenses and data/API terms, so the adapter boundary keeps licensing and availability independent of Paper IR.
